Built for the documents you generate every day.

Not a 1.x compatibility museum. Not an HTML engine. A writer for commercial PDFs.

Honest layout

Nested tables, row spans, repeating footer rows, and mixed columns. Italic is a real face. A custom brand font falls back to Skald Sans for missing glyphs.

Safe composition

Merge and stamp received supplier files. Launch and JavaScript actions are stripped. Indirect /Contents and /Annots resolve. Output is always PDF 2.0.

Symbols that scan

EAN-13, UPC-A, Code 128, GS1-128, and QR are vector ImageSource values. Tests decode them with ZXing after PDFBox rendering — not by inspecting our own bits.

Tiny subsets

TrueType is subset and embedded once per face. Unused OpenType layout tables are dropped. A Latin invoice stays tens of kilobytes, not hundreds.

Zero runtime deps

JPMS modules, JDK image I/O, nothing else. The build fails if a third-party library enters the production classpath.

Apache 2.0

Use it in commercial products without an AGPL conversation. IBM Plex faces ship under the SIL Open Font License.

Start in one dependency.

Release 1.7.0 is on Maven Central. Java packages stay org.skaldpdf.

dependencies {
    implementation("no.beint.skaldpdf:skald-layout:1.7.0")
    implementation("no.beint.skaldpdf:skald-barcode:1.7.0") // optional symbols
    implementation("no.beint.skaldpdf:skald-labels:1.7.0")  // optional stickers
}
byte[] invoice = Pdf.create(document -> {
    document.setMargins(40, 40, 40, 40);
    document.setFirstHeader(page -> new Paragraph("Northstar Ledger · original"));
    document.setFooter(18, page -> new Paragraph(page.pageNumber() + " / " + page.pageCount())
        .setTextAlignment(TextAlignment.CENTER));
    document.add(new Paragraph("Invoice 2026-1001").bold().setFontSize(20));
    document.add(new Image(new QrCode("https://pay.example/inv/2026-1001")).scaleToFit(72, 72));
});

Requires JDK 25+. See the repository, capability matrix, and roadmap.
